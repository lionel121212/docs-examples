# שרת התכנון החכם (AI) של מציק משימות

שרת קטן (Cloudflare Worker) שמקבל תיאור חופשי של היום ומחזיר רשימת משימות מסודרת.
הוא משתמש ב-**Gemma 4 של Google דרך Cloudflare Workers AI**. זה חינמי עד המכסה היומית של Cloudflare, ולא צריך מפתח API. התשובה מגיעה בפורמט JSON קבוע ונבדקת בשרת לפני שהיא נשלחת לאפליקציה.

**למה צריך שרת:** הוא שומר את החשבונות והמנויים, ומגביל את השימוש ב-AI כדי שהמכסה החינמית לא תיגמר בגלל משתמש אחד.

## נקודות קצה
- `POST /onboard`: ניתוח השאלון של משתמש חדש (תובנה, 3 המלצות ותוכנית). **חינמי למשתמש**, ומוגבל ל-5 ניתוחים ביום לכל כתובת IP ו-3 לכל מכשיר, אם מחברים KV.
- `POST /plan`: תכנון לפי תיאור חופשי. **פרימיום בלבד**.
- `GET /me`: בודק אם למשתמש יש פרימיום (מנוי או קוד בודק).

## חשבונות (מכשיר אחד בכל פעם)
- `POST /auth/register`, `POST /auth/login`, `POST /auth/logout`, ובנוסף `GET/PUT /sync` לגיבוי הנתונים.
- **סיסמאות:** נשמרות כגיבוב PBKDF2 עם salt. הטוקן נשמר רק כגיבוב SHA-256.
- **מכשיר אחד:** התחברות ממכשיר שני מחזירה `409 other_device` עם שם המכשיר המחובר. רק התחברות חוזרת עם `force: true` **והסיסמה** מנתקת את המכשיר הקודם, וזה מקבל `401 session_revoked` בפנייה הבאה שלו.
- **פרימיום:** קוד בודק שמוזן כשמחוברים (`POST /redeem`) הופך את כל החשבון לפרימיום, בכל מכשיר.
- **הגנה:** עד 20 ניסיונות התחברות ביום לכל אימייל ו-60 לכל IP. עובד רק עם ה-KV.
- **איפוס סיסמה:** `POST /auth/forgot` שולח במייל (דרך Resend) קוד של 6 ספרות, תקף ל-15 דקות ועד 5 ניסיונות. `POST /auth/reset` מחליף את הסיסמה, מנתק את כל המכשירים ומחבר את המכשיר הנוכחי.
  הגדרה: `npx wrangler secret put RESEND_API_KEY`, ו-`MAIL_FROM` בקובץ `wrangler.toml`.

## חבר מחייב
- `POST /buddy/request {email}` שולח בקשה. `POST /buddy/accept {id}` מאשר (רק מי שקיבל את הבקשה). `POST /buddy/remove {id}` מסיר. עד 10 חברים לכל משתמש.
- `PUT /report` מקבל מהאפליקציה כמה משימות בוצעו היום ואתמול. `GET /buddy` מחזיר לכל חבר שאישר את ההתקדמות שלו.
- התראה שנשלחת לחבר גם כשהאפליקציה שלו סגורה דורשת Firebase. בינתיים העדכון מופיע כשפותחים את האפליקציה.

## מי יכול להשתמש
- **מנויים:** נבדקים מול RevenueCat (`REVENUECAT_SECRET`). מפעילים כשהאפליקציה בחנויות ויש בה מנוי.
- **בודקים:** קוד מתוך `ACCESS_CODES`. כך אפשר לנסות את התכנון כבר עכשיו, בלי חנות.
- כל מי שאינו מנוי או בודק מקבל 402, והאפליקציה מציגה מסך "פרימיום".

## העלאה (פעם אחת)
1. פותחים חשבון חינמי ב-cloudflare.com.
2. מריצים:
   ```bash
   cd task-nagger-server
   npm install
   npx wrangler login
   npx wrangler secret put ACCESS_CODES         # למשל: mycode123
   npx wrangler kv namespace create LIMITS     # מומלץ: הגבלת שימוש והגנה על התחברות
   npx wrangler d1 create task-nagger          # חשבונות וסנכרון
   # מעתיקים את ה-database_id לקובץ wrangler.toml (החלק של d1_databases) ואז:
   npx wrangler d1 migrations apply task-nagger --remote   # מריץ גם את 0002 (איפוס סיסמה) ואת 0003 (חברים)
   # מעתיקים את ה-id שמתקבל לקובץ wrangler.toml (החלק של kv_namespaces)
   npx wrangler deploy
   ```
   בסוף מתקבלת כתובת, למשל `https://task-nagger-planner.<שם>.workers.dev`.
3. מכניסים את הכתובת ב-`task-nagger/app.json`, בשדה `extra.plannerUrl`, ודוחפים. GitHub בונה APK חדש.

## עלות
חינם: Workers AI כולל מכסה יומית חינמית. אם היא נגמרת, השרת מחזיר "עמוס", והשאלון באפליקציה עובר לניתוח המקומי.

`npm test` מריץ את הבדיקות עם תשובה מדומה (לא עולה כסף). `npm run typecheck` בודק טיפוסים.
