# Sim Controller (Assetto Corsa + טלפון/טאבלט)

שרת קטן ל-Windows שמציג על הטלפון או הטאבלט:
- דשבורד טלמטריה מ-Assetto Corsa (מהירות, סל"ד, הילוך, גז, בלם, דלק)
- חלון מוזיקה עם השיר והזמר שמתנגנים כרגע (YouTube Music וכל נגן מדיה של Windows)
- כפתורים שנשלחים למשחק כמקשים (אורות, מגבים, pit limiter וכו')

ההגה והדוושות של Fanatec לא מושפעים בכלל. הם מדברים עם AC ישירות.

## דרישות

- Windows עם Assetto Corsa (AC המקורי)
- Python 3.10 ומעלה
- Android Platform Tools (`adb`) ב-PATH
- טלפון או טאבלט אנדרואיד עם USB debugging

## התקנה (פעם אחת)

1. במכשיר: **הגדרות → מידע על הטלפון → מספר build** (לחיצה 7 פעמים), ואז **אפשרויות מפתח → USB debugging**.
2. מחברים את המכשיר למחשב בכבל. מאשרים את ההרשאה במכשיר, וסומנים **"תמיד לאפשר מהמחשב הזה"**.
3. במחשב:
   ```bat
   pip install -r requirements.txt
   adb devices
   ```
   המכשיר צריך להופיע עם `device` (לא `unauthorized`).
4. ב-AC: **Settings → Controls**, ומגדירים כל כפתור כמו ב-`config.json`. למשל: אורות → `L`, מגבים → `W` וכו'.
5. אם צריך, מעדכנים את `config.json` כך שהמקשים יתאימו למה שמוגדר ב-AC.

## הפעלה

- מחברים את הכבל. מריצים `start.bat`, שממתין למכשיר, מפעיל את ה-`adb reverse`, פותח את הדשבורד בדפדפן של המכשיר, ומריץ את השרת.
- אפשר לחבר את הסקריפט לתזמון ב-**Task Scheduler** שרץ בהתחברות ל-Windows, כדי שלא צריך להפעיל כלום ידנית.

## הערות חשובות

- **הפתיחה האוטומטית של האפליקציה נעשית מהמחשב, לא מהטלפון.** אנדרואיד לא מאפשר לאפליקציה לפתוח את עצמה כשמחברים כבל למחשב.
- הדשבורד נפתח בדפדפן של המכשיר (Chrome). אם תרצה אפליקציה נייטיבית במסך מלא ובמצב אופקי קבוע, זה שלב נפרד.
- **iPhone או iPad לא יעבדו**, כי ל-iOS אין ADB.
- חיבור AC לא נבדק על מחשב אמיתי בסביבה שבה נכתב הקוד. לפני ההרצה הראשונה, בדוק שהמשחק פעיל ושהשרת עולה.
- קריאת `acpmf_physics` ו-`winsdk` דורשת Windows. לא נבדקה בסביבת פיתוח זו.
