# Sim Controller

אפליקציה לטלפון או לטאבלט אנדרואיד שמתחברת בכבל USB למחשב שמריץ Assetto Corsa:
- **בצד שמאל:** 12 כפתורי זכוכית צבעוניים עם אייקונים (אורות, מגבים, מצלמה, איפוס, pit limiter, הילוך למעלה ולמטה, מנוע, ABS, בקרת אחיזה, איזון בלמים, רדיו). כל לחיצה נשלחת למשחק כמקש במקלדת.
- **בצד ימין:** מה שמתנגן עכשיו ב-YouTube Music במחשב: תמונת אלבום, שם השיר, הזמר, פס התקדמות, וכפתורי נגינה, הבא, הקודם, ערבוב וחזרה.

ההגה והדוושות של Fanatec לא מושפעים. הם ממשיכים לעבוד מול המשחק כרגיל.

## מה צריך

- מחשב Windows עם Assetto Corsa
- [Python 3.10 ומעלה](https://www.python.org/downloads/). בהתקנה, לסמן **Add Python to PATH**.
- [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) (כולל `adb`). לחלץ לתיקייה ולהוסיף אותה ל-PATH.
- טלפון או טאבלט אנדרואיד וכבל USB

## התקנה (פעם אחת)

1. **בטלפון:** הגדרות ← אודות הטלפון ← פרטי תוכנה ← ללחוץ 7 פעמים על **מספר Build**. אחר כך: הגדרות ← אפשרויות מפתח ← להפעיל **ניפוי באגים ב-USB**.
2. **במחשב:** לפתוח שורת פקודה בתיקייה הזו ולהריץ:
   ```bat
   pip install -r requirements.txt
   ```
3. **לחבר את הטלפון בכבל.** בטלפון תופיע שאלה אם לאפשר ניפוי באגים. לסמן **"אפשר תמיד ממחשב זה"** וללחוץ אישור.
4. **ב-Assetto Corsa:** Settings ← Controls, ולמפות כל פעולה למקש שלה לפי `config.json`:

   | כפתור | מקש |
   |---|---|
   | אורות | L |
   | מגבים | W |
   | מצלמה | C |
   | איפוס | R |
   | Pit limiter | P |
   | הילוך למעלה | E |
   | הילוך למטה | Q |
   | מנוע | I |
   | ABS | A |
   | בקרת אחיזה | T |
   | איזון בלמים | B |
   | רדיו | H |

   אם יש לך מקשים אחרים במשחק, אפשר לשנות אותם ב-`config.json` במקום.
5. **הפעלה אוטומטית (מומלץ):** להריץ פעם אחת את `install-autostart.bat`. מעכשיו הכל יעלה לבד כשנכנסים ל-Windows. לביטול: `remove-autostart.bat`.

## שימוש

מחברים את הכבל, והאפליקציה נפתחת בטלפון לבד, במסך מלא ובמצב אופקי. בחיבור הראשון היא גם מותקנת לבד.

אם לא הגדרת הפעלה אוטומטית, מריצים קודם את `start.bat`.

- מנתקים את הכבל: האפליקציה מציגה "ממתין למחשב".
- מחברים שוב: היא נפתחת מחדש.

## בדיקה בלי המשחק

```bat
python server.py --demo
```
מציג שיר לדוגמה, והלחיצות על הכפתורים רק מודפסות בחלון. כך אפשר לבדוק את החיבור לטלפון בלי Assetto Corsa.

## אם משהו לא עובד

- **האפליקציה לא נפתחת:** להריץ `adb devices`. אם רשום `unauthorized`, לאשר את ההודעה בטלפון. אם המכשיר לא מופיע בכלל, לנסות כבל אחר. חלק מהכבלים מיועדים לטעינה בלבד.
- **רשום "אין חיבור למחשב":** חלון השרת (Sim Controller Server) לא פועל. להריץ `start.bat` שוב.
- **הכפתורים לא עושים כלום במשחק:** לבדוק שהמקשים ב-AC זהים ל-`config.json`, ושחלון המשחק פעיל (בפוקוס).
- **אין שיר:** לנגן משהו ב-YouTube Music במחשב. הנתונים מגיעים מ-Windows, כך שזה עובד מהדפדפן או מאפליקציית YouTube Music.
- **שני מכשירים מחוברים בבת אחת:** הסקריפט תומך במכשיר אחד בכל פעם.

## קבצים

| קובץ | מה הוא עושה |
|---|---|
| `start.bat` | מפעיל את השרת, ובכל חיבור כבל מתקין ופותח את האפליקציה |
| `server.py` | השרת במחשב: כפתורים למשחק, ומידע על המוזיקה |
| `config.json` | הכפתורים: מקש, אייקון, צבע, והאם הכפתור נשאר דלוק |
| `web/index.html` | מה שמוצג בטלפון |
| `apk/SimController.apk` | האפליקציה לטלפון |
| `android/` | קוד המקור של האפליקציה |
