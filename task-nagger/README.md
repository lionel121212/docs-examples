# מציק משימות

אפליקציית אנדרואיד (Expo / React Native) שמזכירה לך משימות בשעה קבועה.
אם לא סימנת "בוצע", הטלפון רוטט ושולח תזכורות חוזרות בלי הפסקה, ומחמירות בנימה, עד שתסמן.

## איך זה עובד
- לכל משימה יש שעה, ימים בשבוע, "להציק כל X דקות", ו"כמה פעמים".
- ההתראות מתוזמנות מראש בטלפון (7 ימים קדימה), לכן הן עובדות גם כשהאפליקציה סגורה.
- לחיצה על "בוצע" מבטלת את שאר ההצקות של אותו יום.
- התזמון מתחדש בכל פעם שפותחים את האפליקציה. **פתח אותה לפחות פעם בשבוע.**
- המשימות שמורות בטלפון בלבד.

## בדיקה מהירה על הטלפון
1. התקן את **Expo Go** מחנות Play.
2. `npm install && npx expo start`, וסרוק את ה-QR.

Expo Go מגביל חלק מהיכולות של ההתראות. להתנהגות מלאה, בנה APK.

## בניית APK להתקנה
```bash
npm install
npx eas-cli@latest login          # חשבון חינמי ב-expo.dev
npx eas-cli@latest build -p android --profile preview
```
בסוף הבנייה מקבלים קישור ל-APK. פותחים אותו בטלפון ומתקינים ("מקורות לא ידועים").

## הגדרות בטלפון שחשוב לעשות
- אשר הרשאת התראות.
- בהגדרות האפליקציה: סוללה, "ללא הגבלה" (כדי שלא יהרגו אותה בשיפור סוללה).
- ערוץ ההתראות "תזכורות משימות" צריך להיות על חשיבות גבוהה עם רטט.
