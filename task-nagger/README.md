# מציק משימות

אפליקציית אנדרואיד (Expo / React Native) שמזכירה לך משימות בשעה קבועה.
אם לא סימנת "בוצע", הטלפון רוטט ושולח תזכורות חוזרות בלי הפסקה, ומחמירות בנימה, עד שתסמן.

## מה יש באפליקציה
- **היום:** המשימות מקובצות לפי קטגוריות, כל אחת עם צבע ואיור, וסרגל התקדמות יומי.
- **השנה שלי:** טבלה שנתית (כמו ב-GitHub). ירוק = הכול בוצע, צהוב/אדום = פספוס. אפשר לסנן לפי קטגוריה או משימה, ללחוץ על יום ולראות מה עשית בו, ויש גם רצף ימים ואחוז הצלחה.
- **איור אוטומטי:** מזהים מילים בשם המשימה ומציירים איור מתאים (סימולטור = הגה, אופניים = אופניים, "לשטוף פנים" = פרצוף עם טיפה ועוד). אפשר לבחור איור אחר, או להעלות תמונה משלך.
- **צבעים וקטגוריות:** לכל משימה צבע לבחירה, ואפשר ליצור קטגוריות חדשות.

## 🌍 שפות
עברית, English, العربية, Русский, Español. השפה נבחרת אוטומטית לפי הטלפון, ואפשר להחליף אותה ב-⚙️. התרגומים נמצאים ב-`src/locales/`.

## 📝 שאלון פתיחה
בפתיחה הראשונה המשתמש עונה על כמה שאלות: מה הוא עושה, שעות, קשיים, מטרות, זמן פנוי, וכמה חזק להציק לו.
ה-AI מנתח את התשובות ובונה תוכנית. המשתמש רואה ממנה 3 משימות, ואת השאר נעולות מאחורי פרימיום, או ממשיך בחינם עם תוכנית ההתחלה.
בלי שרת, האפליקציה מייצרת ניתוח ותוכנית בסיסיים בעצמה (`src/analysis.ts`).

## ✨ תכנון חכם (AI)
כפתור "תכנן לי את השבוע עם AI" במסך היום. כותבים איך רוצים שהשבוע ייראה, מקבלים רשימת משימות, ובוחרים מה להוסיף.
ה-AI הוא Gemma 4, שרץ חינם ב-Cloudflare. הכפתור דורש את השרת שבתיקייה `task-nagger-server/` (הוראות שם) ומנוי פרימיום או קוד בודק.

## איך זה עובד
- לכל משימה יש שעה, ימים בשבוע, "להציק כל X דקות", ו"כמה פעמים".
- ההתראות מתוזמנות מראש בטלפון (7 ימים קדימה), לכן הן עובדות גם כשהאפליקציה סגורה.
- לחיצה על "בוצע" מבטלת את שאר ההצקות של אותו יום.
- התזמון מתחדש בכל פעם שפותחים את האפליקציה. **פתח אותה לפחות פעם בשבוע.**
- המשימות שמורות בטלפון בלבד.

## התקנה על הטלפון (בלי חשבון Expo)
בכל דחיפה לריפו, GitHub בונה קובץ APK בעצמו (`.github/workflows/build-task-nagger-apk.yml`).
1. בריפו ב-GitHub: **Actions**, אחר כך **Build task-nagger APK**, ובוחרים את הריצה האחרונה.
2. מורידים את `task-nagger-apk`, או את `task-nagger.apk` מעמוד **Releases**, ישירות מהטלפון בכרום.
3. פותחים את הקובץ ומאשרים "התקנה ממקור לא ידוע". האפליקציה מתקינה את עצמה עם האייקון שלה.

אפשר גם לבנות בעצמך: `npx eas-cli@latest build -p android --profile preview` (דורש חשבון חינמי ב-expo.dev).

## הגדרות בטלפון שחשוב לעשות
- אשר הרשאת התראות.
- בהגדרות האפליקציה: סוללה, "ללא הגבלה" (כדי שלא יהרגו אותה בשיפור סוללה).
- ערוץ ההתראות "תזכורות משימות" צריך להיות על חשיבות גבוהה עם רטט.
